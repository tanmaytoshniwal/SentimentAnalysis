#SentimentAnalysis

There are links to 5 blog articles each to the files blogs_file_1.txt and blogs_file_2.txt

Our aim is to build a sentiment ranking program that does the following:
1. Read the url’s present in both the files
2. Scrape the text from each of the links
3. Run sentiment analysis on each document
4. Rank the documents based on the sentiment analysis score (Positive -> Negative)
